## 1. 木陰とは
- **名前**：「木陰の◯◯会｜ここち」。◯◯は型で入れ替わります（木陰の対話会／木陰の読書会／木陰の映画シェア会／木陰のワークショップ）
  - 「ここち」はうってぃとぎっしーの活動全体の名前、「木陰」はこのプロジェクトのブランド名です
- **コンセプト**：慌ただしい日常から、ふうっと一息つける場所。評価・判断されず、素の自分で、自分の内面とつながる
- **位置づけ**：インナークエスト・ライフクエストへの入り口。世界観を体験してもらい、深い探求への意志を育てる
- **参加する人にとって**：自分のアプローチを探り、自分の体験したい現実を創る実践の場
- **うってぃにとって**：実験ではなく本番の場
- **大原則**：運営が削られないこと。事務はシステムが引き受ける

## 2. 基本のルール
- **最少人数の決まりはありません。** ホストだけでも開催し、中止の判定もしません。一般の方の参加がなくても開催します
- **ホスト**：だれでもなれます（運営・IQ受講生・一般の方）
- **時間**：1回3時間（例 13:00〜16:00）。前半2時間がテーマに沿った本編、後半1時間は感想の投稿とフリートーク
- **場所**：基本はイバフォルニア・ベース。指定があれば別の場所でも開催できます
- **定員**：8名（ホストを含む。運営は含まない）。企画ごとに変えられます
- **申込・キャンセル**：当日の開始時刻まで
- **グランドルール**（申込時に同意が必須）
  1. 人のことも自分のことも、評価・判断しない
  2. アドバイスしない（ただ受け取り合う）
  3. 相手の話を最後まで聴ききる
  4. ここで聞いた話は、外に持ち出さない
  5. 安心して自分の内面とつながる時間を大切にする

## 3. 5つの型
| 型 | 表に出る名前 | 中身 |
|---|---|---|
| **共感セッション**（看板） | 木陰の対話会 | ホストの今の悩みが起点。ホスト→共鳴した参加者の順に、ひとり20〜30分の紐解きを2〜3人。終わるたびに全員がニーズカードを選び、一言書いて話した人に贈る。最後にチェックアウト |
| 自己理解ワークショップ | 木陰のワークショップ | メンタルモデルワークブックやインナークエストのワーク（紐解き以外） |
| 読書会 | 木陰の読書会 | 1冊を順番に声に出して回し読み（30分程度）。本は持っていなくてOK |
| 映画シェア会 | 木陰の映画シェア会 | 事前に同じ映画を観てきて対話 |
| その他 | 木陰の対話会 | 自由な企画 |

### 共感セッションの流れ（13:00〜16:00の例）
| 時間 | 内容 |
|---|---|
| 13:00〜13:10 | チェックイン＆グランドルールの共有 |
| 13:10〜13:45 | セッション①：ホスト → ニーズカードの贈り物 |
| 13:45〜14:20 | セッション②：共鳴した参加者 → ニーズカードの贈り物 |
| 14:20〜14:45 | 時間があればセッション③、なければ休憩・余韻 |
| 14:45〜15:00 | 全員でチェックアウト |
| 15:00〜16:00 | 感想の投稿とフリートーク |

時間を均等割りして全員を浅く扱うことはしません。自分の番が来なかった人も、聴くことで共鳴し、チェックアウトで言葉にします。

## 4. 人の区分と料金（当日現金）
| 区分 | 参加費 | 場所代 | 申込シート・人数 |
|---|---|---|---|
| 運営（うってぃ・ぎっしー） | なし | なし | 登録しない・数えない（申し込みもできない） |
| IQ受講生（ライフクエストのメンバーを含む） | 0円 | あり | 登録する・数える |
| 一般・初回 | 1,000円 | あり | 登録する・数える |
| 一般・2回目以降 | 6,000円 | あり | 登録する・数える |

- **ホストの料金**：ホストかどうかに関係なく、区分どおりです（一般の方がホストなら一般の初回／2回目以降）
- **イバフォルニア・ベース**：場所代は1人500円
- **別の場所**：上限つきの割り勘
  - 打ち合わせで「場所代の合計」と「1人あたりの上限」を決めます
  - 参加者は合計を人数で割った額（10円単位で切り上げ）。上限は超えません。人数が増えると安くなります
  - 足りない分・端数はホストが負担します（運営がホストなら運営が負担）
  - 例：合計3,000円・上限1,000円 → 2人なら参加者1,000円・ホスト2,000円／4人なら全員750円
- **発信・口コミ割引**：申込時の自己申告で参加費から1,000円引き（初回なら参加費0円）
- **初回料金**：最初に申し込んだ1件だけ。その申込をキャンセルすると、次の申込が自動で初回料金に戻ります

## 5. 流れ（だれが何をするか）
1. **打ち合わせ**（うってぃ＋ホスト）：運営メニューで、ホスト・型・企画の想い・日時・場所を入力
2. **文章と画像**：Geminiが文章の下書きを作り、二人で手直し。背景を選ぶとInstagram投稿用（4:5）の画像ができる（上部に「木陰の◯◯会」、木陰の枠・日時入り）。投稿文は日時・料金・ハッシュタグ込みで自動で組み立て
3. **公開**：申込画面に並ぶ。運営以外のホストは自動で参加者に登録
4. **うってぃ**：ここちのInstagramに投稿（ホストを共同投稿者・メンションに）
5. **一般の方**：Instagramのプロフィール → 公式LINE → LINEの中の申込画面で申し込み
6. **3日前の12時**：参加者全員へ「3日後は木陰です」のリマインド。運営2名へ人数のお知らせ → 会場の予約・確認
7. **当日**：本編2時間が終わると、一般の参加者へ「感想の投稿のお願い」。終了時刻で「終了」に

## 6. LINEのお知らせ（無料枠は月200通）
| 内容 | 宛先 | 通数 |
|---|---|---|
| 申込・キャンセル直後の確認（名前・料金入り） | 本人 | 無料 |
| 申込・キャンセルの知らせ（日付・タイトル） | 公式LINEの受信箱（運営が見る） | 無料 |
| 3日前のリマインド | 参加者全員 | 数える |
| 3日前の人数のお知らせ | 運営2名 | 数える |
| 本編後の感想の投稿のお願い | 一般の参加者全員 | 数える |
| 3日前以降の申込・キャンセル | ホスト（運営以外のとき） | 数える |
| LINEの外で申し込まれた場合（3日前以降の回のみ） | 運営2名 | 数える（まれ） |

目安：1回10〜15通、月8回で80〜120通。

## 7. 画面
- **申込画面**（LINEの中で開く）：募集中／わたしの予約／お便り（やってほしいテーマを届ける）／申込状況
- **申込状況で見られる範囲**：IQ受講生は募集中の回の名前と区分。一般の方のホストは自分の回だけ。運営はすべて
- **運営メニュー**：木陰をつくる／イベント一覧（人数・集金予定・申込者・「同じ内容で別の日につくる」）／お便り
- **個人情報の取り扱い**：申込ボタンの上と画面下からリンク

## 8. 仕組みと費用
- 画面は GitHub Pages、処理は Google Apps Script、データは Google スプレッドシート。すべて無料で、サーバーなし
- スプレッドシート：名簿・イベント・申込・テーマのお便り・送信ログ。行の追加・削除や書き換えは自由。1行目の見出しとシート名だけは変えない
- 名簿の「区分」をIQ受講生にすると料金が自動で切り替わる。「呼び名」を入れるとホスト名として表示
