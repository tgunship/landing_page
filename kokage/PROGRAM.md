# 木陰のプログラム（型と場の回し方）

Gemini との相談で決まった、木陰の中身（ソフト面）の記録です。
システムでは「型」をイベント作成時に選べ、Gemini の文章・画像・申込画面・LINEの案内に反映されます（型の説明は `gas/Logic.gs` の `FORMATS`）。

## 5つの型

| 型 | 中身 | 作品名 |
|---|---|---|
| **共感セッション**（看板） | ホストがいま抱えている悩み・痛みを起点に、紐解きセッションとニーズカードの贈り合いをする | なし |
| **自己理解ワークショップ** | 『メンタルモデルワークブック』やインナークエストのワーク（紐解き以外）をみんなでやる | なし |
| **読書会** | 1冊を真ん中に置き、順番に声に出して回し読み（30分・1章くらい）→ 感じたことをシェアして対話。本は持っていなくてよい | 本のタイトル（任意） |
| **映画シェア会** | 同じ映画を事前に観てきて、感じたことをシェアして対話 | 映画のタイトル（必須） |
| **その他** | 型にとらわれない自由な企画（海辺の散歩、お茶を飲みながら話す会 など） | なし |

## 共感セッションの流れ（13:00〜16:00の例）

| 時間 | 内容 |
|---|---|
| 13:00〜13:20 | チェックイン＆グランドルールの共有（20分）。「全員を深く扱うことはできないが、相手の話を最後まで聴ききることで共鳴が起きる」という前提をここで伝える |
| 13:20〜14:05 | セッション①（45分）：**ホスト**を最初に。紐解き → 全員がニーズカードを1枚選び、一言書いて話者に贈る |
| 14:05〜14:50 | セッション②（45分）：**参加者**。同じくニーズカードの贈り物 |
| 14:50〜15:00 | 全員でチェックアウト（10分）：他の人の話を聴いて、自分の中に何が響いたか・どんな気づきがあったか |
| 15:00〜16:00 | 感想の投稿（Instagram など）とフリートーク。15:00ごろ、一般の参加者に「感想の投稿のお願い」がLINEで届く |

大事にすること
- **時間を均等割りして全員を浅く扱うことはしない。** ホスト → 参加者の順に、ひとり45分で深く潜る（2人）
- ホストは「教える人」ではなく「いちばんの当事者」。最初に弱さを開示することで、場の安心が最初から高くなる
- ニーズカードを贈るのはアドバイスではなく、痛みの奥の願いへの共感。セッションを受けなかった人も場に深く関わる
- 自分の番が来なかった人は、共鳴によって自分を見つめ、チェックアウトで言葉にする

## 企画を出しやすくするために（IQ受講生・一般の方のホスト）
1. **お便りに乗っかる**：一般の方から届いた「テーマのお便り」（運営メニュー・お便りタブ）から、「これなら話を聞けそう」を選んで手を挙げるだけでよい
2. **痛みと願いカードをテーマにする**：思いつかないときは、気になったカードを1枚引いてそのままテーマに（例：「正解がわからない」→「『正解がわからなくて動けない』をただ語り合う木陰」）
3. **型を選んで少し自分の色を足す**：上の5つから選ぶだけ
4. **打ち合わせは「種」だけでOK**：「最近、子育てでイライラして…」のようなモヤモヤ1つで、うってぃとの15分の打ち合わせを入れてよい。対話しながら、運営メニューで Gemini も使って一緒に形にする
