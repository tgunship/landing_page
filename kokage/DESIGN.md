# 設計判断メモ（Gemini との相談結果からの変更点）

Gemini と作った指示書をベースに、実装にあたって以下を判断・変更しました。

## 1. 構成：Python サーバー → Google Apps Script ＋ GitHub Pages
指示書は FastAPI（Python）＋スプレッドシート＋GAS のタイマー、でした。
しかしデータベースもタイマーも Google 側にあるなら、処理ごと Apps Script に置けばサーバーが要りません。

- サーバー代・スリープ対策・デプロイ先の選定が不要
- 画像合成は Pillow（サーバー）ではなくブラウザの canvas で実施（打ち合わせ中に即プレビューでき、日本語フォントの用意も不要）
- Apps Script の制約：Webhook のリクエストヘッダー（署名）を読めない → Webhook URL に秘密のトークンを付けて代替

## 2. 運営メニューも LINE ログインで本人確認
運営（うってぃ・ぎっしー）の判定は、スクリプト プロパティの LINE ユーザーID で行います。パスワードは作りません。
パソコンのブラウザで開くと LINE ログイン画面が出ます。

## 3. 決めたこと（うってぃ確認済み）
| 項目 | 決めたこと |
|---|---|
| 最少人数・中止 | なし。ホストだけでも開催し、一般の方の参加がなくてもよい（以前の「3日前の開催判定・中止・別日で再企画」はやめた） |
| 3日前の知らせ | 開催3日前の12時に、参加者全員へ「3日後です」のリマインド（日時・場所・料金・グランドルール）、運営2名へ人数のお知らせ（会場の予約・人数確認用。判定はしない） |
| 名前 | 「木陰の◯◯会｜ここち」。◯◯は型で入れ替わる（共感セッション・その他＝対話会、読書会、映画シェア会、ワークショップ）。『』は本や映画の題名にも使うため、木陰には付けない |
| 1回の時間 | 3時間：本編2時間＋感想の投稿・フリートーク1時間 |
| お礼LINE | 本編2時間が終わったとき、一般の参加者全員へ。後半の投稿の時間に合わせて「感想の投稿のお願い」。割引にチェックした方には発信のお願いを添える |
| 場所 | 基本はイバフォルニア・ベース（1人500円）。別の場所も可。その場合は上限つきの割り勘：場所代の合計を運営以外の参加者（ホスト含む）で割り（10円単位で切り上げ）、打ち合わせで決めた1人あたりの上限を超えない。足りない分・端数はホストが負担（運営がホストなら運営）。申込・キャンセルのたびに計算し直す |
| 運営 | うってぃ・ぎっしーの2名。費用なし・申込シートに登録しない・人数に数えない。申込画面からも申し込めない |
| ホスト | だれでもなれる（運営・IQ受講生・一般の方）。運営以外のホストは参加者に登録し、人数に数える。料金は区分どおり（一般の方のホストは一般の初回／2回目以降） |
| 区分 | 「一般」「IQ受講生」の2つ。ライフクエストのメンバーもIQ受講生（「LQメンバー」と書いてあってもIQ受講生として扱う） |
| グランドルール | 評価・判断しない／アドバイスしない／相手の話を最後まで聴ききる／口外しない／自分の内面とつながる時間を大切にする |
| 料金 | IQ受講生：場所代のみ。一般：初回1,000円・2回目以降6,000円＋場所代。発信・口コミの自己申告で1,000円引き（初回なら参加費0円） |
| 「初回」の定義 | 有効な「一般」の申込のうち、最初に申し込んだ1件。キャンセルで空いたら次の申込が自動で初回に戻る（募集中の回のみ） |
| 定員 | 8名（ホスト含む・運営は含まない。企画ごとに変更可） |
| 申込・キャンセルの締切 | 開始時刻まで |
| 運営への申込・キャンセルの知らせ | Push しない。参加者のトークから公式LINEへ届く合図のメッセージに日付・タイトルを載せ（人数は参加者本人のトークにも残るため載せない）、公式LINEの受信箱で確認（無料）。3日前の知らせの後にLINEの外で申し込まれて合図が送れなかったときだけ運営へ Push |
| ホストへの知らせ | 3日前の知らせの後の申込・キャンセルを、運営以外のホストへ Push |
| 申込状況の閲覧 | IQ受講生：募集中の回の名前・区分。一般の方のホスト：自分がホストの募集中の回だけ。運営：全回・全項目 |
| ホスト名 | 名簿の「呼び名」があればそれ、なければLINEの表示名 |
| 型 | 共感セッション／自己理解ワークショップ／読書会／映画シェア会／その他から選ぶ。読書会は本のタイトル（任意）、映画シェア会は映画のタイトル（必須）。型と作品名は画像・投稿文・申込画面・LINEの案内に入り、Gemini の文章にも反映（`PROGRAM.md`） |
| 個人情報 | `privacy.html` を用意し、申込画面の申込ボタンの上とフッターからリンク |
| 画像サイズ | 投稿 4:5（1080×1350）のみ |
| Instagram 投稿文 | AIの本文＋日時・料金・ハッシュタグを自動で組み立て（料金をAIに書かせない） |
| スプレッドシートの見出し | 手で直しやすいよう日本語。列は見出しの文字で探すので並べ替えても動く |

## 4. Gemini の説明で補足・訂正が必要だった点
- **LINE の通数見積もり**：数えられるのは3日前のリマインド（参加者全員）・人数のお知らせ（運営2名）・お礼（一般の参加者）・ホストへの知らせ。1回あたり10〜15通、月8回で80〜120通。運営メニューに今月の送信数を表示する。
- **liff.sendMessages による無料返信**：LINE アプリ内で開いたときのみ動く。パソコンのブラウザ等では確認メッセージは届かない（画面には表示）。
- **LIFF の公開**：LINE ログインチャネルを「公開済み」にしないと、一般の方は使えない。
- **Gemini の無料枠**：Google のプロダクト改善に入力が使われることがある。企画の想い（個人情報を含まない文章）だけを送る設計にしている。参加者の個人情報は送らない。
- **Instagram API**：投稿・ストーリーズの自動化は技術的には可能だが、リンクスタンプ・音楽・ハイライトは不可。手動投稿の結論どおり実装していない。
