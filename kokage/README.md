# 木陰（Kokage）マネジメントシステム

ライフクエストのメンバーがホストになる「木陰」の、企画づくり・Instagram用画像・LINEでの申し込み・開催判定・名簿管理をまとめて自動化する仕組みです。

## 全体像

```
[Instagram 投稿] ──プロフィールのリンク──▶ [公式LINE] ──リッチメニュー──▶ [申込画面 (LIFF)]
                                                  ▲                               │
                                    無料の返信 / 開催判定のお知らせ                  ▼
[運営メニュー (admin.html)] ───────────▶ [Google Apps Script] ◀──────▶ [スプレッドシート（名簿・イベント・申込）]
   打ち合わせ中に企画を入力                     15分ごとのタイマーで             うってぃが直接見て、直接直せる
   → Gemini で文章 → 画像を保存               開催判定・お礼LINE
```

| 置き場所 | 中身 | 費用 |
|---|---|---|
| GitHub Pages（このリポジトリの `kokage/`） | 申込画面 `index.html`、運営メニュー `admin.html`、画像合成 `poster.js` | 無料 |
| Google Apps Script（スプレッドシートに付属） | `gas/*.gs`：API・LINE連携・開催判定・Gemini | 無料 |
| Google スプレッドシート | データベース | 無料 |
| LINE公式アカウント | 申し込み窓口・お知らせ | 無料（月200通まで。後述） |
| Gemini API | 文章の下書き | 無料枠 |

サーバーを持たないので「スリープして判定が動かない」「データが消える」心配がありません。

## 毎回の流れ（だれが何をするか）

### 打ち合わせ（うってぃ＋ホストのメンバー）
1. Zoom などで画面共有しながら、運営メニュー（`admin.html`）の「木陰をつくる」を開く
2. ホスト・企画の想い（たらたら書いてOK）・開催日・開始時間を入力 → 「AIで文章をつくる」
3. タイトル・案内文・投稿本文を二人で手直し（画像にすぐ反映されます）
4. 背景を選ぶ（自分の写真のアップロードも可。どの写真でも木陰の枠が必ず重なります）→「画像を保存」
5. 「公開して募集開始」→ 申込画面に並び、ホストは自動で参加者に登録されます（場所代500円）

### うってぃ
- 保存した画像と「投稿文をコピー」した文章で、ここちのInstagramに投稿（ホストを共同投稿者・メンションに）
- 開催判定のLINE（開催決定／中止）が届いたら、開催決定ならイバフォルニア・ベースを予約
- 開催決定後に追加申込・キャンセルがあればLINEが届くので、予約人数を調整
- 当日、場を開く

### 自動でやること
- 申込・キャンセル直後の確認メッセージ（その人の名前・料金入り。無料のReply API）
- 開催3日前の12時に判定：**合計4名以上 かつ 一般2名以上** → 開催決定／未達なら中止。参加者全員と運営3名へLINE
- 終了時刻に「本日はありがとうございました」（発信・口コミ割引にチェックした方へ）
- 中止になった回を「別日で再企画」すると、前回申し込んだ一般の方へ特別ご案内
- 終了したイベントを「終了」にし、次回から2回目以降の料金に

### 料金（自動計算・当日現金）
| 区分 | 参加費 | 場所代 | 合計 | 発信・口コミ割引にチェック |
|---|---|---|---|---|
| LQメンバー・IQ受講生（ホスト含む） | 0円 | 500円 | **500円** | （対象外） |
| 一般・初回 | 1,000円 | 500円 | **1,500円** | 500円 |
| 一般・2回目以降 | 6,000円 | 500円 | **6,500円** | 5,500円 |

- 「初回」＝中止にならなかった回への「一般」としての申込が、他に1件もないこと
- LQメンバー・IQ受講生は、スプレッドシートの「名簿」で **区分** を「LQメンバー」「IQ受講生」に変えるだけ（LINEユーザーIDで自動判別）

## はじめの設定（1回だけ）

所要時間の目安：1〜2時間。順番どおりに進めてください。

### 1. スプレッドシートと Apps Script
1. Google ドライブで新しいスプレッドシートを作る（名前例：「木陰 データベース」）
2. メニュー「拡張機能 → Apps Script」を開く
3. `kokage/gas/` の各ファイル（`Api.gs` `Config.gs` `Cron.gs` `Gemini.gs` `Line.gs` `Logic.gs` `Setup.gs`）を、同じ名前で作って中身を貼り付ける
   - 左の「⚙ プロジェクトの設定」で「appsscript.json をエディタで表示」をオンにし、`appsscript.json` も貼り付け
   - （clasp を使う場合は `kokage/gas` をそのまま push しても構いません）
4. スプレッドシートを再読み込み → メニュー「木陰 → ① 初期設定」を実行（権限の許可を求められたら許可）
   - 「名簿」「イベント」「申込」「テーマのお便り」「送信ログ」のタブができます

### 2. LINE Developers
1. [LINE Developers](https://developers.line.biz/) に、ここちの公式LINEと同じプロバイダーでログイン
2. **Messaging API チャネル**（公式LINEのもの）
   - 「チャネルアクセストークン（長期）」を発行 → 控える
   - LINE Official Account Manager の「応答設定」で、**Webhook：オン／チャット：オン／応答メッセージ：オフ** にする
     （チャットをオンにしておけば、うってぃが手動でも返信できます）
3. **LINE ログイン チャネル**を新しく作る（同じプロバイダー）
   - 「チャネルID」を控える
   - 「リンクされたLINE公式アカウント」に、ここちの公式LINEを設定
   - LIFF タブで LIFF アプリを追加
     - サイズ：Full
     - エンドポイントURL：`https://tgunship.github.io/landing_page/kokage/`
     - Scope：`openid` `profile` `chat_message.write` にチェック
     - 友だち追加オプション：On (Aggressive)
     - → 「LIFF ID」を控える
   - チャネルを **公開済み** にする（開発中のままだと運営以外が使えません）

### 3. Gemini API キー
[Google AI Studio](https://aistudio.google.com/apikey) で API キーを作成 → 控える（クレジットカード登録は不要）

### 4. スクリプト プロパティ
Apps Script の「⚙ プロジェクトの設定 → スクリプト プロパティ」に追加：

| プロパティ | 値 |
|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | Messaging API のチャネルアクセストークン |
| `LINE_LOGIN_CHANNEL_ID` | LINE ログイン チャネルのチャネルID |
| `LIFF_ID` | LIFF ID |
| `GEMINI_API_KEY` | Gemini の API キー |
| `ADMIN_LINE_USER_IDS` | 運営3名のLINEユーザーID（カンマ区切り）※手順6で取得 |
| `DRY_RUN` | 最初は `true`（LINEを実際には送らずログだけ残すテストモード） |

`SPREADSHEET_ID` と `WEBHOOK_TOKEN` は初期設定で自動で入ります。
人数や金額を変えたいときも、ここに `MIN_TOTAL_PARTICIPANTS` などを足せばコードを触らずに変えられます（`Config.gs` 参照）。

### 5. ウェブアプリとしてデプロイ
1. Apps Script 右上「デプロイ → 新しいデプロイ → 種類：ウェブアプリ」
   - 実行するユーザー：**自分**／アクセスできるユーザー：**全員**
2. 表示された URL（`https://script.google.com/macros/s/…/exec`）を控える
3. スプレッドシートのメニュー「木陰 → 設定チェック」で表示される **Webhook URL** を、Messaging API チャネルの Webhook URL に設定し、「Webhookの利用」をオン
   - 「検証」ボタンがエラー表示になることがありますが、Apps Script の仕様（リダイレクト）によるもので、実際には届きます。手順6で確認できます
4. コードを直したときは「デプロイを管理 → 編集 → バージョン：新バージョン」で更新（URLは変わりません）

### 6. 運営3名のLINEユーザーIDを登録
1. うってぃ・ぎっしー・はるみさんが、それぞれ公式LINEを友だち追加し、トークで「**ID**」と送る
2. 返ってきた `U…` で始まるIDを、`ADMIN_LINE_USER_IDS` にカンマ区切りで入れる
3. 同じように、LQメンバー・IQ受講生にも友だち追加（＋何か一言送信）してもらうと「名簿」に載るので、**区分** を書き換える

### 7. 画面の設定（このリポジトリ）
`kokage/config.js` の `LIFF_ID` と `API_URL`（手順5の URL）を書き換えて push。GitHub Pages に反映されます。

### 8. リッチメニュー・Instagram
- LINE Official Account Manager の「リッチメニュー」で3つのボタンを作る
  - 募集中の木陰：`https://liff.line.me/<LIFF_ID>`
  - わたしの予約：`https://liff.line.me/<LIFF_ID>?tab=mine`
  - テーマを届ける：`https://liff.line.me/<LIFF_ID>?tab=request`
- ここちのInstagramのプロフィールのリンクに `https://liff.line.me/<LIFF_ID>` を設定
  （タップ → LINEが開き、友だち追加をすすめられ、申込画面が開きます）

### 9. 定期実行とテスト
1. メニュー「木陰 → ② 定期実行をオンにする」（15分ごと）
2. `DRY_RUN=true` のまま、運営メニューで近い日付のテスト企画を作り、自分のLINEで申し込み・キャンセルしてみる
   - テスト中だけ `MIN_TOTAL_PARTICIPANTS=1`・`MIN_GUEST_PARTICIPANTS=0` にしておくと判定まで試せます
   - 「今すぐ開催判定・終了処理を実行」で判定を待たずに動かせます。送るはずだった内容は Apps Script の「実行数」ログで見られます
3. 問題なければ `DRY_RUN` を削除（または `false`）、テスト用の人数設定も削除、テストの行も消して本番開始

## スプレッドシートを手で直すとき

- ✅ **してよいこと**：行の追加・削除、セルの書き換え、列の並べ替え、列の追加、フィルタや色づけ
- ❌ **しないこと**：1行目（見出し）の文字を変える／見出しのある列を消す／タブ名を変える
- よくある操作
  - LQメンバー・IQ受講生にする：「名簿」の **区分** をプルダウンで変更
  - 電話で受けたキャンセル：「申込」の **状態** を「キャンセル」に
  - 企画をやめる：「イベント」の **状態** を「中止」に（自動の中止LINEは送られません。必要なら公式LINEから個別に）
  - 料金を特別に変える：「申込」の **当日お支払い** を書き換え（開催決定LINEにはその金額が載ります）

## LINE の無料枠（月200通）について
- 申込・キャンセル直後の返信、「ID」への返信、友だち追加のあいさつは **Reply API なので無料・無制限**
- 数えられるのは：開催判定（参加者＋運営3名）、終了時のお礼、特別ご案内、開催決定後の追加申込・キャンセル通知（運営3名）
- 目安：1回あたり 10〜15通 → 月8回で 100通前後。運営メニュー「イベント一覧」に今月の送信数が出ます
- 申込画面を LINE の外（パソコンのブラウザなど）で開いた場合は、確認メッセージがトークに届きません（画面には表示されます）

- ロジックのテスト：`TZ=Asia/Tokyo node --test kokage/tests/logic.test.js`
- `gas/Logic.gs` は Google のサービスに依存しない純粋な関数だけにしてあり、Node でテストできます
