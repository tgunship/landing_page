# 木陰（Kokage）マネジメントシステム

「木陰」の、企画づくり・Instagram用画像・LINEでの申し込み・人数のお知らせ・名簿管理をまとめて自動化する仕組みです。

## 全体像

```
[Instagram 投稿] ──プロフィールのリンク──▶ [公式LINE] ──リッチメニュー──▶ [申込画面 (LIFF)]
                                                  ▲                               │
                                       無料の返信 / お知らせ                        ▼
[運営メニュー (admin.html)] ───────────▶ [Google Apps Script] ◀──────▶ [スプレッドシート（名簿・イベント・申込）]
   打ち合わせ中に企画を入力                     15分ごとのタイマーで             うってぃが直接見て、直接直せる
   → Gemini で文章 → 画像を保存               人数のお知らせ・お礼LINE
```

| 置き場所 | 中身 | 費用 |
|---|---|---|
| GitHub Pages（このリポジトリの `kokage/`） | 申込画面 `index.html`、運営メニュー `admin.html`、画像合成 `poster.js`、個人情報の取り扱い `privacy.html` | 無料 |
| Google Apps Script（スプレッドシートに付属） | `gas/*.gs`：API・LINE連携・定期処理・Gemini | 無料 |
| Google スプレッドシート | データベース | 無料 |
| LINE公式アカウント | 申し込み窓口・お知らせ | 無料（月200通まで。後述） |
| Gemini API | 文章の下書き | 無料枠 |

サーバーを持たないので「スリープして定期処理が動かない」「データが消える」心配がありません。

## 基本のルール
- **最少人数の決まりはありません。ホストだけでも開催します。中止の判定もありません。** 一般の方の参加がなくても開催します
- **ホスト**：だれでもなれます（運営・IQ受講生・一般の方）
- **1回3時間**（例 13:00〜16:00）：前半2時間がテーマに沿った本編、後半1時間は感想の投稿やフリートーク
- **場所**：基本はイバフォルニア・ベース。指定があれば別の場所でも開催できます
- **グランドルール**（申込時に同意が必須）：評価・判断しない／アドバイスしない／相手の話を最後まで聴ききる／ここで聞いた話は外に持ち出さない／自分の内面とつながる時間を大切にする
- **定員**：8名（ホストを含む。運営は含まない）。企画ごとに変えられます
- **申込・キャンセル**：当日の開始時刻まで

## 毎回の流れ（だれが何をするか）

### 打ち合わせ（うってぃ＋ホスト）
1. Zoom などで画面共有しながら、運営メニュー（`admin.html`）の「木陰をつくる」を開く
2. ホスト・**型**（共感セッション／自己理解ワークショップ／読書会／映画シェア会／その他。詳しくは `PROGRAM.md`）・企画の想い（たらたら書いてOK）・開催日・開始時間・場所を入力 → 「AIで文章をつくる」
   - 場所をイバフォルニア・ベース以外にすると「場所代の合計」の欄が出ます（割り勘用。無料なら0）
3. タイトル・案内文・投稿本文を二人で手直し（画像にすぐ反映されます）
4. 背景を選ぶ（自分の写真のアップロードも可。どの写真でも木陰の枠が必ず重なります）→「画像を保存」（Instagram投稿用 4:5）
5. 「公開して募集開始」→ 申込画面に並びます
   - 運営（うってぃ・ぎっしー）がホスト：費用なし。参加者として登録せず、人数にも数えません
   - それ以外（IQ受講生・一般の方）がホスト：参加費なし・場所代のみで参加者として登録し、人数に数えます
   - 運営は申込画面から申し込むこともできません（人数に数えないため）
   - 運営メニューの「イベント一覧」の「同じ内容で別の日につくる」で、過去の回を下書きにできます

### うってぃ
- 保存した画像と「投稿文をコピー」した文章で、ここちのInstagramに投稿（ホストを共同投稿者・メンションに）
- 開催3日前の12時に「人数のお知らせ」がLINEで届くので、会場の予約・人数を確認
- 申込・キャンセルは、**公式LINEの受信箱（LINE Official Account Manager のチャット）** で確認
  - 参加者のトークから「【木陰】申し込みました／キャンセルしました」＋日付・タイトルが届きます（無料。参加者本人のトークにも残るので人数は載せません。人数は「申込状況」で確認）
  - 「（人数お知らせ後）」と付いていたら、会場予約の人数を調整
  - パソコンのブラウザなどLINEの外で申し込まれ、受信箱に届かなかった場合だけ、人数お知らせ後の回なら公式LINEから運営2名へ通知します
- ホストが運営以外の回は、人数お知らせ後の申込・キャンセルがホストにもLINEで届きます
- 当日、場を開く

### 自動でやること
- 申込・キャンセル直後の確認メッセージ（その人の名前・料金入り。無料のReply API）
- 開催3日前の12時：運営2名へ人数のお知らせ（別会場なら1人あたりの場所代も）
- 本編2時間が終わったとき：一般の参加者全員へ「感想の投稿のお願い」（後半1時間の投稿の時間に合わせて。割引にチェックした方には発信のお願いを添えて）
- 終了時刻：その回を「終了」にし、次回から2回目以降の料金に
- 料金の見直し：初回の申込をキャンセルしたら次の申込を初回料金に戻す／別会場の割り勘を人数に合わせて直す

### 申込状況を見る
申込画面の「申込状況」タブ（見られる人にだけ表示されます）
- **IQ受講生**：募集中の回の人数と、申込者の名前・区分（料金・紹介者は見えません）
- **一般の方のホスト**：自分がホストの募集中の回だけ（同上）
- **運営**：すべての回・料金・紹介者まで。運営メニューの「イベント一覧」でも見られます

### 料金（自動計算・当日現金）
| 区分 | 参加費 | 場所代（イバフォルニア・ベース） | 合計 | 発信・口コミ割引にチェック |
|---|---|---|---|---|
| 運営（うってぃ・ぎっしー） | — | — | **なし** | — |
| ホスト（IQ受講生・一般の方） | 0円 | 500円 | **500円** | （対象外） |
| IQ受講生 | 0円 | 500円 | **500円** | （対象外） |
| 一般・初回 | 1,000円 | 500円 | **1,500円** | 500円 |
| 一般・2回目以降 | 6,000円 | 500円 | **6,500円** | 5,500円 |

- **別会場の場合**：場所代は「場所代の合計 ÷ 運営以外の参加者（ホスト含む）の人数」（10円単位で切り上げ）。申込・キャンセルのたびに自動で計算し直します。参加費はそのまま
  - 例：場所代3,000円で4名 → 1人750円
- 「初回」＝有効な「一般」としての申込のうち、いちばん先に申し込んだ1件。キャンセルすると、次に申し込んでいる回が**自動で初回料金に戻ります**（キャンセルの確認でお知らせ）
- IQ受講生（ライフクエストのメンバーを含む）は、スプレッドシートの「名簿」で **区分** を「IQ受講生」に変えるだけ（LINEユーザーIDで自動判別）

## はじめの設定（1回だけ）

所要時間の目安：1〜2時間。順番どおりに進めてください。

### 1. スプレッドシートと Apps Script
1. Google ドライブで新しいスプレッドシートを作る（名前例：「木陰 データベース」）
2. メニュー「拡張機能 → Apps Script」を開く
3. `kokage/gas/` の各ファイル（`Api.gs` `Config.gs` `Cron.gs` `Gemini.gs` `Line.gs` `Logic.gs` `Setup.gs`）を、同じ名前で作って中身を貼り付ける
   - 左の「⚙ プロジェクトの設定」で「appsscript.json をエディタで表示」をオンにし、`appsscript.json` も貼り付け
   - （clasp を使う場合は `kokage/gas` をそのまま push しても構いません）
4. スプレッドシートを再読み込み → メニュー「木陰 → ① 初期設定」を実行（権限の許可を求められたら許可）
   - 「名簿」「イベント」「申込」「テーマのお便り」「送信ログ」のタブができます

### 2. LINE Developers
1. [LINE Developers](https://developers.line.biz/) に、ここちの公式LINEと同じプロバイダーでログイン
2. **Messaging API チャネル**（公式LINEのもの）
   - 「チャネルアクセストークン（長期）」を発行 → 控える
   - LINE Official Account Manager の「応答設定」で、**Webhook：オン／チャット：オン／応答メッセージ：オフ** にする
     （チャットをオンにしておけば、うってぃが手動でも返信できます）
3. **LINE ログイン チャネル**を新しく作る（同じプロバイダー）
   - 「チャネルID」を控える
   - 「リンクされたLINE公式アカウント」に、ここちの公式LINEを設定
   - LIFF タブで LIFF アプリを追加
     - サイズ：Full
     - エンドポイントURL：`https://tgunship.github.io/landing_page/kokage/`
     - Scope：`openid` `profile` `chat_message.write` にチェック
     - 友だち追加オプション：On (Aggressive)
     - → 「LIFF ID」を控える
   - チャネルを **公開済み** にする（開発中のままだと運営以外が使えません）

### 3. Gemini API キー
[Google AI Studio](https://aistudio.google.com/apikey) で API キーを作成 → 控える（クレジットカード登録は不要）

### 4. スクリプト プロパティ
Apps Script の「⚙ プロジェクトの設定 → スクリプト プロパティ」に追加：

| プロパティ | 値 |
|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | Messaging API のチャネルアクセストークン |
| `LINE_LOGIN_CHANNEL_ID` | LINE ログイン チャネルのチャネルID |
| `LIFF_ID` | LIFF ID |
| `GEMINI_API_KEY` | Gemini の API キー |
| `ADMIN_LINE_USER_IDS` | 運営（うってぃ・ぎっしー）のLINEユーザーID（カンマ区切り）※手順6で取得 |
| `DRY_RUN` | 最初は `true`（LINEを実際には送らずログだけ残すテストモード） |

`SPREADSHEET_ID` と `WEBHOOK_TOKEN` は初期設定で自動で入ります。
定員や金額を変えたいときも、ここに `VENUE_FEE` や `DEFAULT_MAX_PARTICIPANTS` などを足せばコードを触らずに変えられます（`Config.gs` 参照）。

### 5. ウェブアプリとしてデプロイ
1. Apps Script 右上「デプロイ → 新しいデプロイ → 種類：ウェブアプリ」
   - 実行するユーザー：**自分**／アクセスできるユーザー：**全員**
2. 表示された URL（`https://script.google.com/macros/s/…/exec`）を控える
3. スプレッドシートのメニュー「木陰 → 設定チェック」で表示される **Webhook URL** を、Messaging API チャネルの Webhook URL に設定し、「Webhookの利用」をオン
   - 「検証」ボタンがエラー表示になることがありますが、Apps Script の仕様（リダイレクト）によるもので、実際には届きます。手順6で確認できます
4. コードを直したときは「デプロイを管理 → 編集 → バージョン：新バージョン」で更新（URLは変わりません）

### 6. 運営（うってぃ・ぎっしー）のLINEユーザーIDを登録
1. うってぃ・ぎっしーが、それぞれ公式LINEを友だち追加し、トークで「**ID**」と送る
2. 返ってきた `U…` で始まるIDを、`ADMIN_LINE_USER_IDS` にカンマ区切りで入れる
   - 名簿の **呼び名** に「うってぃ」「ぎっしー」と入れておくと、ホスト名としてその名前が表示されます（LINEの表示名より優先。ほかの人も同じ）
3. はるみさんを含むIQ受講生にも友だち追加（＋何か一言送信）してもらうと「名簿」に載るので、**区分** を「IQ受講生」に書き換える

### 7. 画面の設定（このリポジトリ）
`kokage/config.js` の `LIFF_ID` と `API_URL`（手順5の URL）を書き換えて push。GitHub Pages に反映されます。

### 8. リッチメニュー・Instagram
- LINE Official Account Manager の「リッチメニュー」で3つのボタンを作る
  - 募集中の木陰：`https://liff.line.me/<LIFF_ID>`
  - 申込状況（IQ受講生・ホスト・運営用。ほかの人には表示されません）：`https://liff.line.me/<LIFF_ID>?tab=status`
  - わたしの予約：`https://liff.line.me/<LIFF_ID>?tab=mine`
  - テーマを届ける：`https://liff.line.me/<LIFF_ID>?tab=request`
- ここちのInstagramのプロフィールのリンクに `https://liff.line.me/<LIFF_ID>` を設定
  （タップ → LINEが開き、友だち追加をすすめられ、申込画面が開きます）

### 9. 定期実行とテスト
1. メニュー「木陰 → ② 定期実行をオンにする」（15分ごと）
2. `DRY_RUN=true` のまま、運営メニューで近い日付のテスト企画を作り、自分のLINEで申し込み・キャンセルしてみる
   - メニュー「今すぐ定期処理（人数のお知らせ・お礼・終了）を実行」で、時刻を待たずに動かせます。送るはずだった内容は Apps Script の「実行数」ログで見られます
3. 問題なければ `DRY_RUN` を削除（または `false`）、テストの行も消して本番開始

## スプレッドシートを手で直すとき

- ✅ **してよいこと**：行の追加・削除、セルの書き換え、列の並べ替え、列の追加、フィルタや色づけ
- ❌ **しないこと**：1行目（見出し）の文字を変える／見出しのある列を消す／タブ名を変える
- よくある操作
  - IQ受講生にする：「名簿」の **区分** をプルダウンで「IQ受講生」に
  - 電話で受けたキャンセル：「申込」の **状態** を「キャンセル」に
  - 料金を特別に変える：「申込」の **当日お支払い** を書き換え（初回かどうか・割り勘の金額が変わらない限り、そのまま残ります）
  - 別会場の場所代を変える：「イベント」の **場所代合計（別会場）** を書き換え（15分以内に割り勘が計算し直されます）

## LINE の無料枠（月200通）について
- 申込・キャンセル直後の返信、「ID」への返信、友だち追加のあいさつは **Reply API なので無料・無制限**
- 数えられるのは：3日前の人数のお知らせ（運営2名）、本編後のお礼（一般の参加者全員）、人数お知らせ後の申込・キャンセル通知（運営以外のホストのみ。運営へは受信箱に届く参加者のメッセージで代える）
- 目安：1回あたり 5〜10通 → 月8回で 40〜80通。運営メニュー「イベント一覧」に今月の送信数が出ます
- 申込画面を LINE の外（パソコンのブラウザなど）で開いた場合は、確認メッセージがトークに届きません（画面には表示されます）
