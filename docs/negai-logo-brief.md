# 願いのロゴ化セッション LP 前提情報

名称は「願いのロゴ化」。「痛みと願い」は「痛みと願いカード」のことで、「願いのロゴ化」セッションの最初に「痛みと願いカード」のセッションを行う。

`negai-logo.html` を作るときに前提とした情報です。出典はチームかもえさの打合せ文字起こし（Googleドライブ上、リポジトリには置かない）と、依頼時に受け取った文言のたたき台です。

## 確認できたこと

- 提供者：チームかもえさ（うってぃ・かんな・ゆーき）
  - うってぃ：痛みカード・願いカードを使った対話と構造化
  - かんな：言葉（文章）のパート
  - ゆーき：絵のパート
- コースは2種類。打合せでは「フルバージョン／1時間バージョン」と呼んでいたものを、LPでは「スタンダード／ショート」と表記
  - スタンダード：2時間30分、25,000円。参加者自身も文章や絵をかくことができる（かかなくてもよい）
  - ショート：1時間、16,000円。対話を聴きながら、ゆーきがその場で絵を描いて贈る
- 料金は2026年11月時点の金額。値上げを検討中との話あり
- 対面が基本。オンラインは「機会があれば」の位置づけ
- 会場によっては会場費を上乗せすることがある
- リトリートや合宿のプログラムとして行う場合は、料金体系が別（体験料・食費などを加算）
- 「痛みから見つめる」理由：願いはいきなり言葉にしにくいが、痛みは身体の感覚として感じやすく、その裏側に願いがあるため
- 持ち帰れるもの：贈られた文章と絵。「お守り」という表現が使われている
- 呼称は「参加者」を使う（「クライアント」は使わない）
